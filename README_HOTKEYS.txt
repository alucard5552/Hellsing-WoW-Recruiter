ГОРЯЧИЕ КЛАВИШИ (работают глобально в Windows, в том числе во время игры):
  • [NumPad 4] - Меню переключения рабочих столов (WoW <-> Основной)
  • [NumPad 5] - Открыть / свернуть панель управления
  • [NumPad 1] - Включить / приостановить авто-набор
  • [F11]      - Ручная калибровка оптического пикселя курсором мыши

РУЧНАЯ НАСТРОЙКА КООРДИНАТ ПИКСЕЛЯ:
  1. В окне панели управления (NumPad 5) доступны поля X и Y.
  2. Вы можете ввести координаты вручную и нажать кнопку [Сохранить X, Y].
  3. Кнопка [Сброс (20, 20)] мгновенно выставляет координаты центра стандартного
     индикатора (верхний левый угол игры).
  4. Либо нажмите кнопку [Курсором (F11)] или клавишу F11:
     наведите мышь на квадрат в игре и нажмите F11 повторно для точного захвата!

КОМАНДЫ В ЧАТЕ World of Warcraft:
  • /kar             - Главное меню настроек авто-набора
  • /kar pixel       - Показать / скрыть тестовый белый квадрат
  • /kar test tank   - Тест срабатывания на танка (голубой пиксель)
  • /kar test heal   - Тест срабатывания на хила (зеленый пиксель)
  • /kar test dps    - Тест срабатывания на ДД (оранжевый пиксель)
  • /pb              - Открыть черный список игроков
  • /kgd             - Дамп текущей группы в лог

КОМПОНЕНТЫ:
  • WoW_Recruiter_Setup.exe        - Автономный установщик с выбором папки WoW
  • WoWSmartRecruiter.exe          - Фоновая служба авто-набора в Program Files
  • MidnightAddons.zip             - Пакет из 76 аддонов (включая Clique и KeyAutoRecruit)
