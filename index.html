👁️

Zero-Taint Optical Bridge

0% модификаций памяти игры и отсутствие хуков DLL. Клиент WoW проецирует субпиксельный цветовой код (24×24 px), а алгоритм OpenCV Template Matching мгновенно считывает решение из DirectX-буфера.

Точность: 100% | Время: < 15 мс
⌨️

Pure Hardware F12 Input

Клик мыши отключен на 100%. Курсор игрока полностью свободен. Двойной ввод клавиши F12 через Win32 PostMessage в дескриптор окна и аппаратный SendInput через синхронизацию AttachThreadInput.

0 мискликов | Фон без перехвата мыши
🖥️

Virtual Desktop Isolation

Окно WoW переносится на скрытый виртуальный рабочий стол Windows (Стол #2). Вы можете работать, играть в другие игры или смотреть 4K фильмы на Столе #1 — рекрутер непрерывно отбирает кандидатов в фоне.

Изоляция PyVDA | 0 помех работе
🕸️

Децентрализованный P2P Mesh

Аддон KAR_P2P_Tester объединяет всех членов группы в P2P-сеть через защищенный аддон-канал C_ChatInfo. База черного списка и история кандидатов синхронизируются без сторонних веб-серверов.

Zero Server Dependency | 100% P2P
🩸

Dark Gothic Web Dashboard

Локальный REST API микросервис (порт 49286) и стилизованный дашборд в эстетике Hellsing. Интерактивная статистика, живая телеметрия OpenCV, Cinzel-шрифты и анимированная печать Кромвеля.

Standalone Chromium App | Порт 49286
🛡️

Многофакторный скоринг

Глубокая эвристическая оценка кандидатов в реальном времени: проверка минимального ilvl, рейтинга Mythic+ (Raider.IO), распределения ролей (1 танк, 1 хил, 3 ДД) и автоматический отсев вагонов.

Точный отсев слакеров | Авто-прием
